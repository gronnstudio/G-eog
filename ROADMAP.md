# Equilibrium — Roadmap

Equilibrium (EOG) is the open-source living knowledge ecosystem for
regenerative thinking, by GRØNN Studio.

The canonical, phased roadmap lives in **[docs/13-roadmap.md](docs/13-roadmap.md)**:

- Phase 1 — Foundation: static seed corpus, canvas graph, Cmd-K, SEO/PWA
- Phase 2 — Memory: Postgres + Prisma, Supabase auth, personal library, server search
- Phase 3 — School: full learning paths, review pipeline
- Phase 4 — Intelligence: embeddings, semantic search, grounded AI assistant
- Phase 5 — Commons: discussions, expert program, open data, i18n

Full design documentation suite: [docs/00-vision.md](docs/00-vision.md) through docs/13.
